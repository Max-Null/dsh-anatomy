## 改动主题明细（α.2 → 0.1.3-alpha.1）

### 1. 会话格式 v2（最大 breaking，09-01 ~ 09-04）
- `feat(session)!: embed assistant streams in format v2`：assistant 流式内容**内嵌持久日志**；新格式删除旧 `chunk-rows.ts`
- `feat(agent): emit live assistant stream frames`：`agent/assistant-stream` 事件 + `SessionAssistantStreamAccumulator`，冷恢复/回放可拿到生成中中间状态（history 接口 `assistantStream` 回放字段）
- `feat(session)!: add released format migration`：新包 `session-format` / `session-format-v0-to-v1` / `session-format-catalog`（v0→v1→v2）
- 迁移兼容系列：v2 stream settlements、迁移工件所有权、surface 顺序校验、body-free 冷列表、迁移数据接受等十余个 fix
- `fix(agent): terminate live assistant attempts`：被取消流走 try/finally 正确关 live 通道

### 2. 跨进程写所有权租约（09-04，Refs #3245）
- `feat(session-persistence-jsonl): cross-process write-ownership lease`：写句柄持**内核级写锁**——POSIX `flock(2)`（fs-ext）/ Windows 路径派生命名内核信号量；**进程死亡内核自动释放**（崩溃持有者永不阻塞后继）；POSIX 校验锁定 inode == 锁路径 inode；读句柄永不碰锁；browser worker 下 stub
- 意义：官方根治"多实例并发写同一会话日志 → seq gap 损坏"问题（与此前工作区 `.tmp-*` 修复工具同源问题）

### 3. 通用文件上传与附件（08-28 ~ 09-01，PR #3109）
- `feat(attachment): store and project generic files`：`attachments.saveFile`（字节级内容寻址，无准入上限）+ `admitEncodedFile`（canonical base64 校验）
- `feat(session-controller): admit files across command flows`；`feat(conversation): stream files through submission lifecycle`（http-bridge/rpc 改造）
- `feat(ui-attachment): unify mixed attachment presentation`：`FileCard.tsx`
- 服务边界重构：isolate/background upload service、prompt admission 收敛等

### 4. 出站网络代理（08-28 ~ 09-04，net 系列）
- `feat(net): route every outbound request through the configured proxy`：新增 `packages/net`（六函数 util → 四函数收敛到 `http-proxy`）
- 语义：本机自身排除、子进程/worker 继承路由、`NODE_USE_ENV_PROXY` 细化；新增 `docs/user/guide/network-proxy` + egress 测试矩阵

### 5. 会话历史与轮次导航（08-31 一批）
- `feat(session-controller): loadThrough deep history paging`、`feat(session-turn-outline): whole-log turn outline projection`、`feat(ui-chat): full-session turn rail with load-and-jump` + scrollable fixed-pitch 轮次栏、settled-response 卡预算预览
- `feat(session-projection): identity-gated change feed` + unit-declared viewKey change token
- `feat(ui-chat): settle jump landings after paging completes`

### 6. read_image 图片卡片（08-29 ~ 09-02）
- `feat(ui-tool): render read_image results as the image`（`tool.call.images` 槽位）+ 嵌套调用支持 + 根调用 meta 缺失回退策略

### 7. skill / 命令模糊排名共享（09-04）
- `feat(web): rank skill candidates with the shared fuzzy name ranker`：`ui-primitives/rank-by-name.ts`（前缀 + 有序子序列对齐加权），`/` 菜单与 skill 统一；slash token 气泡装饰、clickable-link LinkIcon 统一

### 8. LLM 模型发现扩展（09-02 ~ 09-04）
- Anthropic Messages 协议模型列表（`GET /v1/models`、`x-api-key`、`anthropic-version`）；解析器同时接受 `data` 数组与富 `models` map；网关 /v1 处理限定到发现

### 9. agent-team / subagent

## 对本工作区的含义

1. **锁 α.2 策略成立**：5 天 5 版 + 2 个格式 breaking；插件生态若跟随主库会持续适配
2. **未来升级最小风险点 = 0.1.2-rc.1**（npm 已发、无 format v2；含绝大多数修复）
3. **0.1.3-alpha.1 未发 npm**，且带 format v2 + 写租约等大改——升级需插件重适配，应在 DSHfork 先做迁移试验
4. fork 上的 `native-cross-session-memory` 与主库无同类冲突（截至本观察日）

## 2026-09-05 补充观察：alpha.1→rc.1 源码构建缺陷（SSiD 适配中发现）

- **现象**：基于 `dsh-v0.1.2-alpha.1` 源码 checkout 的桌面壳（SSiD Electron），web 壳构建产物
  `apps/web/dist`（`index-D-eoFxDP.js` 424KB，SHA256 前缀 `C43DC436`）丢失 7 个函数级导出
  （`FISH_LOGO_VIEWBOX` / `diffTotals` / `saveFile` / `ConnectionIndicator` /
  `IconAlarmClockOutline16` / `IconClockOutline16` / `IconDatabaseOutline16`，grep 计数 0/7）——
  `packages/client/web/src/seed.ts` 的 `import * as UiPrimitives` 静态表被 tree-shake，
  页面 client 模块引用 undefined → React `#130 (sidebar.settings)` + `conversation: …reading 'height'`。
- **对照**：同源码树的 `dsh-v0.1.2-rc.1` tag，`pnpm run clean` 后全量 `pnpm run build`，
  产物 `index-Df-65__b.js` 423KB（SHA256 `9E845CBB`）7 项导出齐全、页面正常。
- **推论**：alpha.1→rc.1 之间官方已在源码层面修复（无单一 tree-shake 修复提交，推测为模块图/打包
  间接触发）；**官方 alpha.1 发布物存在该缺陷，建议复核**（rc.1 已无）。
- **构建注意**：直接 `vite build`（apps/web 单步）会用各包 `lib/` 预编译残留（client 包 main=lib），
  tag 切换后必须 `pnpm run clean` + 全量 `pnpm run build`（增量 tsc 缓存撕裂会 MISSING_EXPORT）。

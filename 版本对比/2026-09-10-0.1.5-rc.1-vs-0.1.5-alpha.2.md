# DSH 主库版本观察：0.1.5-rc.1 vs 0.1.5-alpha.2

> 观察时间：2026-09-10 · 观察库：`DSHfork/`（独立克隆观察站） · 基线：`dsh-v0.1.5-alpha.2`

## 结论速览

| 问题 | 答案 |
|---|---|
| 什么时候更新的 | 0.1.5-alpha.2（09-09 22:13）→ 0.1.5-rc.1（09-10 09:36），**不足 12 小时** |
| 发布 NPM 了吗 | **已发布，且被标记为 `latest`**。dist-tags：`latest`=0.1.5-rc.1、`next`=0.1.5-rc.1、`alpha`=0.1.5-alpha.2 |

## 关键变化：npm latest 跳版

| 项 | 09-09 实测 | 09-10 实测 |
|---|---|---|
| npm `latest` | 0.1.2-rc.1 | **0.1.5-rc.1** |
| npm `next` | 0.1.2-rc.1 | 0.1.5-rc.1 |
| npm `alpha` | 0.1.5-alpha.2 | 0.1.5-alpha.2 |
| 最新 tag | `dsh-v0.1.5-alpha.2` | **`dsh-v0.1.5-rc.1`** |
| `origin/master` | `b2e3b2a012` | `aa8262ec09` |

`latest` 从 0.1.2-rc.1 直接跳到 0.1.5-rc.1——默认安装路径（`pnpm add @deepseek-ai/dsh`）现在拿到的是 0.1.5-rc.1。

## rc.1 提交构成（13 个非 merge）

- **LLM（3）**：default Chat Completions to DeepSeek V41 Flash ／ retain V4 models alongside V41 Flash ／ restore V4 Flash Vision Exp catalog entry
- **Sidebar（3）**：refine guide start page and quiet stat pill noise ／ pin the guide hero to the pure-gray ramp ／ refine sidebar document previews
- **client（3）**：keep preview scrollports current ／ refresh slot catalog ／ address sidebar and stats review feedback
- **test（3）**、**release（1）**

rc.1 之后的 9 个提交全是 docs/i18n（README 校对、BibTeX 引用）。

## 对本工作区的影响

1. **桌面端（`apps/desktop`、`apps/desktop-host`）零改动** → `2026-09-10-官方桌面壳评估与方案B决策.md` 中所有桌面端实测结论在 rc.1 上仍然成立（不开监听端口、配置层禁用 webserver/web-runtime、独占 `profiles/desktop`）。
2. **connection 零改动** → carrier-neutral 语义（`inject` 只有 `credentials`、支持 POST、有 `requestBody` 字段）在 rc.1 上成立。**§12 规范草案的技术前提已经满足**。
3. **npm latest 已是 0.1.5-rc.1** → 该文档 §13 的「重启条件①（内核可升到 0.1.5+）」**已满足**；条件②（官方桌面端发布安装包）仍待满足。
4. 官方桌面端仍未发布：npm `@deepseek-ai/dsh-desktop` 无包、GitHub Release 的 `assets` 为空。

## 方法备忘（下次续写）

- npm 查询：`https://registry.npmjs.org/-/package/@deepseek-ai/dsh/dist-tags`（轻量）
- 当前最新 tag：`dsh-v0.1.5-rc.2`

## 同日晚补充：0.1.5-rc.2（09-10 21:50）

- tag `dsh-v0.1.5-rc.2`（`fb2c4b9e69`，Yichen Jiang）；rc.1 → rc.2 仅 **4 提交（2 个非 merge）**：`feat(web): backport feedback and file refinements to 0.1.5` + release 提交。
- **四条关键线零实际改动**：`apps/desktop`、`apps/desktop-host`、`packages/client/connection`、`packages/preset/persona` 在 rc.1→rc.2 的唯一提交都是 `release(dsh): 0.1.5-rc.2`（只改版本号）。→ 本工作区的官方桌面壳评估与升级差异清单结论**不受影响**。
- npm dist-tags：`latest`=`0.1.5-rc.1`（未动）、**`next`=`0.1.5-rc.2`**、`alpha`=`0.1.5-alpha.2`。即 rc.2 走 `next` 预发布通道，官方未把它标记为推荐版。
- rc.2 之后 `origin/master` 又前进 **139 提交**（多为 CI / test 修复）。
- **升级目标建议**：跟 `latest`（rc.1），或等 0.1.5 正式版（非 rc）再升；不必追 `next`。
